Ergens Hyso, Kristine Megrelishvili and Antonio Kanani

StudyHub is a web app for student teams. It keeps courses, deadlines, tasks, meetings and notes in one place, so a group spends less time coordinating and more time on the work.

We are three computer science exchange students at DHBW Karlsruhe. This blog is the weekly log of how we build StudyHub. The same documents and the code are in the GitHub repository.
